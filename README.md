# Football Match Tracker

A Python application that fetches historical football match data using the API-Sports Football API.

## Features
- Search matches by league.
- Select a season.
- View teams and match dates.
- Display match scores.
- Handle API errors.

## Technologies
- Python
- Requests
- API-Sports Football API
- python-dotenv

## Setup
1. Install dependencies:
   `pip install -r requirements.txt`
2. Create a `.env` file and add:
   `FOOTBALL_API_KEY=your_api_key`
3. Run:
   `python football.py`

**Note:** An API-Sports key is required. Available seasons depend on your API plan.
